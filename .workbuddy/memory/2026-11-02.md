# 2026-11-02

## coolha.com 产品官网 SEO 与质量修复

对 Next.js 16 官网做了全站审计（5 页面 × 3 语言），跑通本地 dev + production build，
用 Playwright 全页截图逐页目视核对，修复了以下问题。

### 根因
根 layout `[locale]/layout.tsx` 用 `getLocale()` 取语言，导致：
- 所有中文页的 `<title>` 输出英文
- `alternates.canonical` 全站硬编码为 `https://coolha.com/en`（子页面继承后全部指向首页）
- `alternates.languages` 的 hreflang 全部指向首页而非对应路径

### 修复清单
1. **500 错误**：metadata 声明了 `/shortcut-icon.png`、`/apple-icon.png`，但 public 下不存在，
   被 i18n 中间件拦截后变成 `Cannot find module '../../i18n/shortcut-icon.png.json'`。
   已用 sharp 从 logo 生成 icon.png(32) / shortcut-icon.png(32) / apple-icon.png(180) / icon128 / icon512。
2. **canonical + hreflang**：新增 `src/lib/seo.ts` 的 `buildAlternates(path, locale)`，
   各页面 layout 各自生成正确的 canonical 与带路径的 hreflang。
3. **首页标题**：`(www)/layout.tsx` 写死 `title: "About"`，导致首页是 " Coolha | About"。
   已移除 metadata，首页改为 server component（新增 `_layout/Home.tsx` 承载 client 内容），
   用 `www.meta_title` / `www.meta_description`（三语）。
4. **AI 页标题重复**：`&` 硬编码在 hero_title 之外，渲染成 "& Web4 & The New Era..."。已删除硬编码 `&`。
5. **RWA 页重复段落**："什么是真实世界资产（RWA）？" 与 "什么是 RWA？" 两段定义重复。
   已合并，第二段标题改为新增键 `tokenization_title`（代币化如何运作 / How Tokenization Works），
   并把物理资产描述补全（加入艺术品、碳信用）。
6. **SEO 文案**：清掉 `+852-XXXX-XXXX` 电话占位符、NFT 品牌营销等过时表述、
   2019 式关键词堆砌 description；FAQ 里 "Base chain / OpenClaw runtime" 无依据（产品截图未见），
   改为 EVM 兼容链表述；BreadcrumbList 结构错误（平级页面被列成层级）改为 WebSite。
7. **manifest.json**：补 /logo/icon512.png，修正 background_color（站点是暗色，原为 #ffffff），
   start_url 改 /en，screenshots 换成真实产品截图。
8. **LCP 优化**：Product.tsx 首张 showcase 图加 `loading="eager"`。
